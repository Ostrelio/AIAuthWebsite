§ 06

Principles

craft bar
squint
One element dominates at 3–6×.
Wordmark, claim, policy cell, or mega figure. A chasm, not a ramp. If two elements compete, demote one or split into two frames.
silence
Sparse plates read 55–75% empty.
The paper is the brand's confidence. The ledger is the one named density exception — nothing else earns that density.
restraint
Accent fires once per frame.
The electric blue appears at full strength exactly once. The semantic triad fires together only in the state-grid plate.
semantics
Allow is green, approval is amber, deny is red.
Carried verbatim from design.md §4. Never swapped for variety. Always paired with a label — color is never the only cue.
slide tell
Headline left, graphic right, every frame.
The anti-pattern that reads as a generic SaaS deck. Lean centered by default; vary the anchor between consecutive frames.
chrome drift
A new hex, radius, or weight the source doesn't define.
Atoms are sacred. If you need a value the frontmatter doesn't carry, promote it as a token first — never invent it inline.
decoration
Multicolor gradients, type shadows, glass chrome.
Depth ceiling is a single lift on the policy cell. Rules do structural work; nothing else gets to decorate.
code on paper
Syntax colors on a light surface.
Code colors (§3) belong only inside the dark code panel. On paper they read as rainbow noise against ink.
